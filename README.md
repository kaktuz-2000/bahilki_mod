# bahilki_mod
Данный мод для майнкрафт добавляет в игру бахилковую руду. С ее помощью можно сделать себе модные бахилки, или просто съесть сам кусочек бахилки, но последствия вас не обрадуют.
Мод сделан для версии игры 26.1.2 fabric. 
Мод можно настраивать самому через MCreator.
Сам готовый мод лежит в этом же репозитории с названием bahilki-1.0.0-fabric-26.1.2.jar
